Botanical Extract Document Package

A document package should help procurement and quality teams connect the sample, specification and commercial quotation.

Core Documents

For botanical extract sourcing, document review is strongest when the buyer connects each file to a specific sample or grade. A COA is useful, but it should be read with the specification and application requirement.

DocumentWhy It Matters
Specification sheetDefines target limits, assay direction, physical properties and quality requirements.
Representative COAShows example batch results and helps the buyer understand release format.
Sample labelConnects the tested sample with lot, grade, date and supplier reference.
Packing detailsSupports storage, warehouse, shipping and first purchase planning.
