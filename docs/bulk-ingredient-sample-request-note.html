Bulk Ingredient Sample Request Note

Prepare sample requests with clear specification, COA, application and packing fields before supplier comparison.

Sample Request Fields

Sample requests work better when the buyer explains how the ingredient will be reviewed. This is especially important for tea powder, fruit powder and plant extract projects where physical behavior and document review happen together.

FieldWhat to prepare
Ingredient targetProduct name, assay range, powder format, grade or application direction.
Sample quantityTesting amount, number of grades and preferred sample label details.
DocumentsSpecification sheet, representative COA, packing note and any quality questionnaire.
Commercial contextExpected order range, destination market, packing preference and project timing.
